# FPGA Verilog 학습 및 최종 프로젝트

본 레포지토리는 Verilog HDL을 이용한 FPGA 기초 논리 회로 설계부터 통신 프로토콜 및 복합 제어 시스템까지의 학습 과정을 기록함. 개별 모듈 단위의 실습을 거쳐, 학습한 모든 기능을 통합한 최종 프로젝트를 구현함.

> **📂 소스 코드 경로 안내**
> 모든 프로젝트(01번 ~ 19번)의 소스 코드는 [`FPGA/ai1/`](FPGA/ai1/) 디렉터리 내부에 위치하고 있습니다.

## 1. 최종 프로젝트 (Final Project)
### 프로젝트 개요
다양한 센서 및 입력 장치(DHT11, DS1302, 로터리 인코더, UART)와 출력 장치(DC 모터, FND, 부저, 서보 모터)를 통합 제어하는 스마트 냉방 제어 시스템(스마트 팬)을 구현함. 각 기능은 독립적인 모듈로 분리되어 하향식(Top-Down) 아키텍처로 통합 설계됨.

### 주요 구현 모듈 및 기능
- **온습도 측정 및 모터 제어 (dht11, dcmotor)**
  - 단선 통신(Single-wire)을 통해 DHT11 센서로부터 현재 온도 및 습도 데이터를 수집함.
  - 현재 온도와 설정 온도(`target_temp`)의 차이를 계산하여 DC 모터의 PWM 듀티비를 자동 조절(팬 속도 가변 제어)함.
- **사용자 입력 및 온도 설정 (rotary_temp_set, debouncer)**
  - 로터리 인코더의 회전 위상차를 인식하여 희망 온도를 설정함.
  - 물리 버튼 입력의 신뢰성을 확보하기 위해 D 플립플롭(2-Stage FF) 기반의 하드웨어 디바운싱(Debouncing) 회로를 적용함.
- **RTC 기반 시간 관리 및 알람 (DS1302, alarm_controller, buzzer)**
  - DS1302 RTC 칩과 동기 직렬 통신하여 실시간 현재 시간을 파악함.
  - 알람 시간을 설정하고, 도달 시 피에조 부저 모듈에 특정 주파수를 인가하여 알람음을 출력함.
- **디스플레이 출력 (fnd_controller)**
  - 4자리 7-Segment(FND)를 시분할 다중화(Multiplexing) 방식으로 제어하여 핀 낭비를 최소화함.
  - 버튼 입력에 따라 현재 시간, 현재 온/습도, 희망 온도 모드로 디스플레이 상태를 전환함.
- **UART 양방향 통신 (uart_controller, uart_cmd_parser)**
  - 외부 기기(PC 등)와 비동기 직렬 통신(UART) 인터페이스를 구축함.
  - 수신된 커맨드 패킷을 파싱하여 원격으로 RTC 시간 갱신 및 알람 설정을 수행함.
- **풍향 제어 (louver_controller)**
  - 서보 모터 구동을 위한 50Hz PWM 신호를 생성하여, 에어컨의 루버(풍향) 회전 기능을 구현함.

## 2. 모듈별 학습 과정 (Learning Process)
FPGA 하드웨어 제어 및 Verilog 설계를 위해 단계별로 진행한 실습 내역임.

- **01. gate_test**: 기본 논리 게이트(AND, OR, NOT 등) 설계 및 동작 검증.
- **02~03. adder / subtractor**: 반가산기, 전가산기 설계 및 이를 활용한 4-bit, 8-bit 가감산기 조합 논리 회로 구현.
- **04. mux_decoder_encoder**: 멀티플렉서, 디코더, 인코더 설계 및 데이터 라우팅 학습.
- **05. btn_debounce**: 물리 버튼의 채터링 현상을 하드웨어적으로 제거하기 위한 디바운싱 회로 설계.
- **06~07. counter / stopwatch**: 플립플롭을 이용한 순차 논리 회로 학습. 상향/하향 카운터 및 FND 동적 구동을 활용한 스톱워치 구현.
- **08. LED_BTN_TEST**: 기본 GPIO 입출력 제어.
- **09~10. FSM (Coffee Machine, Pattern)**: 유한 상태 기계(FSM) 설계. 무어(Moore)/밀리(Mealy) 머신 상태도를 기반으로 한 자판기 제어 및 특정 패턴 인식기 구현.
- **11. shift_register**: 시프트 레지스터 설계 및 데이터 직렬/병렬 변환 제어 학습.
- **12. pwm_dcmotor**: 카운터를 이용한 PWM 신호 생성 및 듀티비 가변을 통한 DC 모터 속도 제어.
- **13~15. buzzer / microwave / melody**: 주파수 분주를 이용한 피에조 부저 제어. FSM과 타이머를 복합 응용한 전자레인지 컨트롤러 설계.
- **16. rotary_encoder**: 로터리 인코더의 2상 출력 위상차 분석 및 카운터 연동 구현.
- **17. uart**: 비동기 직렬 통신(UART)의 Baudrate 생성기, 송수신기(TX/RX) 설계 및 원형 큐(Circular Queue)를 이용한 데이터 버퍼링 구현.
- **18. DS1302**: 3선식 동기 직렬 통신 프로토콜 설계 및 외부 RTC 칩 레지스터 제어.

## 3. 설계 주안점 및 기술적 특징 (Technical Highlights)
- **원형 큐(Circular Queue) 버퍼링을 적용한 UART 통신**: 통신 중 데이터 병목과 유실을 방지하기 위해 FIFO 형태의 하드웨어 원형 큐를 구현함. 수신된 데이터를 버퍼에 저장하고 메인 로직 처리 속도에 맞춰 꺼내 쓰는 비동기 아키텍처를 설계함.
- **FSM(상태 머신) 기반 직렬 통신 프로토콜 직접 제어**: DS1302(RTC) 칩 제어를 위해 `IDLE → COMMAND → READ/WRITE → NEXT_REG`로 이어지는 유한 상태 기계(FSM)를 구축함. 라이브러리 없이 클럭 엣지 단위의 3선식 동기 직렬 통신(SPI-like) 타이밍을 하드웨어 레벨에서 직접 제어함.
- **하드웨어 카운터를 활용한 정밀 클럭 분주**: 100MHz 시스템 기본 클럭을 목적에 맞게 분주(Divider)하여 다중 제어 환경을 구성함. UART용 Baudrate(9600bps) 펄스, 서보 모터 구동용 50Hz PWM 신호, 피에조 부저의 음계 주파수(Hz) 등을 독립적인 타이머로 동시 생성함.
- **2-Stage D-FF 기반 하드웨어 디바운싱(Debouncing)**: 모든 물리 버튼 입력단에 D-플립플롭을 2단 직렬 연결한 시프트 레지스터 구조를 적용하여, 기계적 접점 진동(채터링)으로 인한 스위칭 오류를 원천 차단함.
